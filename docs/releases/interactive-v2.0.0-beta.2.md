# MacPet 互动番外版 2.0 Beta 2 · 键盘联动修复

互动版侧重打字联动；经典版侧重安静陪伴，两者并行保留。本次只更新 Mac 互动版。

- 修复启动时未获权限、授权后不再尝试连接的问题，增加自动重连和唤醒/激活后的恢复。
- 右键「键盘互动」显示关闭、等待权限、正在监听状态。
- 表情解码和切换移出系统监听回调，降低监听超时风险。
- 保留自选联动表情及停键 0.5 秒恢复原表情的行为。
- 仅保存监听状态和是否收到过事件的诊断标记，不记录字符、按键码或输入内容。

## 安装与权限（升级必读）

macOS 14+，Universal 同时支持 Intel 和 Apple Silicon Mac。解压后退出旧互动版，将新应用放入固定安装位置再启动；表情和设置保留。

当前使用本地临时签名，未作 Apple 公证。新版签名身份可能变化：输入监控中的旧开关即使打开，新版也可能显示权限被拒绝。此时在系统设置 → 隐私与安全性 → 输入监控中移除旧条目，重新添加本次安装的「MacPet 互动版.app」，开启权限并退出重开。不要关闭系统整体安全保护。安全输入（例如密码输入）期间可能无法检测。

## 验证

重新授权后键盘联动已由用户实际确认恢复；通用构建和 20 项核心回归测试通过。Intel 架构已构建，未在 Intel 真机验证；核心回归测试不等同于系统权限测试。
