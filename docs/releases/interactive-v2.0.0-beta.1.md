# MacPet 互动番外版 2.0 Beta 1（macOS）

这是侧重键盘互动的独立衍生版本，与侧重安静陪伴的经典版 1.2.2 并行保留，不替代经典版。Windows 目前继续使用经典版。

- 右键「键盘互动」选择任意现有表情，启用打字联动。
- 打字时临时切换，停键 0.5 秒后恢复原表情；可以随时关闭。
- 保留九个 GIF、透明鹦鹉图标、表情导入/删除/批量删除、动画速度及省电设置。
- 独立应用身份和数据目录，不覆盖经典版；额外表情请重新导入。

## 安装与权限

macOS 14 或以上，Universal 包支持 Apple Silicon 和 Intel Mac。解压后将「MacPet 互动版.app」拖入应用程序。
首次启用请允许系统设置 → 隐私与安全性 → 输入监控中的互动版，必要时退出重开。仅检测按键活动，不记录字符、不上传输入。安全输入（例如密码输入）可能暂停检测。
应用仅本地签名，未作 Apple 公证；首次运行可能需在系统设置中允许打开。

## 验证范围

通用构建、20 项核心回归测试通过。用户已试用互动功能；Intel 架构已构建，未在 Intel 真机验证。本版本为 Beta，不宣称完成实际电池续航测量。
