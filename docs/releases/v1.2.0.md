# MacPet 1.2.0 · 动画表情版

内置当前全部 **9 个 GIF 表情**，无需额外导入即可使用。

## 下载与安装

下载 `MacPet-1.2.0-universal.zip`，解压后把 `MacPet.app` 拖入「应用程序」。
支持 **macOS 14+，Apple Silicon / Intel**，不需要 Swift 或 Xcode。

本版本没有 Developer ID 签名与 Apple 公证，首次打开可能被系统拦截。核对来自本仓库后，按系统提供的右键「打开」或「系统设置 → 隐私与安全性」提示允许启动。不同 macOS 版本的提示可能不同。

## 更新内容

- 右键切换表情，保留 GIF 自带的透明动画。
- 多文件导入 GIF / PNG，名称来自文件名。
- 列表右侧「×」删除单项；「批量删除…」勾选多项，支持全选及取消全选。
- 动画默认 **0.5× 半速**，可切换至 0.25× / 0.75× / 1×，重启后记住设置。
- 修复系统开启“减少动态效果”时 GIF 不播放的问题。
- 默认开启省电模式，最多每秒更新 12 次，系统低电量模式降至最多每秒 6 次。
- GIF 按需换帧、静态 PNG 停止动画计时、隐藏时停帧，减少无效刷新。
- 保留专注计时、番茄投喂、拖动和调整大小。

## 数据与升级

退出旧版后替换应用即可。首次启动自动加入内置表情，不覆盖同 ID 的现有表情；删除后不会重启复活。导入副本移入废纸篓，原始素材不受影响。
发行包不含作者的专注记录、窗口位置和个人偏好。

校验包完整性：`shasum -a 256 -c SHA256SUMS.txt`。
