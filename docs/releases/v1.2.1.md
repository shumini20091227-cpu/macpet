# MacPet 1.2.1 · 精简桌宠功能

移除专注计时与喂番茄功能，让 MacPet 专注于桌面陪伴与动画表情。

## 本次更新

- 删除开始/停止专注、双击查看时长、番茄奖励、食物数量及投喂选项。
- 删除关联计时与账本逻辑、喂食动画和专注看书状态。
- 保留全部 9 个 GIF 表情、批量导入、切换、单项/批量删除。
- 保留 0.25× / 0.5× / 0.75× / 1× 动画速度及省电模式。
- 保留拖动、调整大小、高光、单击打开 ChatGPT、隐藏与退出。

## 下载与安装

下载 `MacPet-1.2.1-universal.zip`，解压后把 `MacPet.app` 拖入「应用程序」。
支持 macOS 14+，Apple Silicon / Intel，不需要 Swift 或 Xcode。

此版本未经过 Developer ID 签名和 Apple 公证，首次启动可能需要按系统的“打开”或“隐私与安全性”提示允许启动；请先核对来源。

## 升级

退出旧版后替换应用。已有表情、动画速度、省电模式和窗口设置保留；不再读取或更新旧版专注及食物数据。

校验完整性：`shasum -a 256 -c SHA256SUMS.txt`。
