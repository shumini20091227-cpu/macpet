# MacPet 1.2.2 · 鹦鹉应用图标

## 本次更新

- 使用透明抠图的鹦鹉作为应用图标，替换通用占位图标。
- 下载解压后，Finder、Dock 和安装后的 MacPet 均使用新图标。
- 提供完整的多尺寸 ICNS，适配普通与 Retina 显示。
- 保留全部 9 个动画表情、表情管理、速度设置和省电模式。
- 延续 v1.2.1：没有专注计时或喂番茄功能。

## 下载与升级

下载 `MacPet-1.2.2-universal.zip`，解压后将 `MacPet.app` 拖入「应用程序」。先退出旧版再替换应用，已有表情和设置保留。
支持 macOS 14+，Apple Silicon / Intel，不需要 Swift 或 Xcode。

此版本没有 Developer ID 签名和 Apple 公证，首次打开可能需要按系统提示允许启动；请先核对下载来源。若 Dock 暂时仍显示旧图标，退出后从应用程序重新打开 MacPet。

校验：`shasum -a 256 -c SHA256SUMS.txt`。
