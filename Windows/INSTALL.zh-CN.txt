MacPet Windows 1.2.2

1. 将压缩包完整解压到一个文件夹。
2. 双击 MacPet.exe 即可运行，无需安装 .NET 或开发工具，也不需要管理员权限。
3. 右键宠物切换表情、导入 GIF / PNG、删除或批量删除、调节速度、省电、调整大小和高光。
4. 拖动移动；选择“调整大小”后拖动四角或滚动鼠标滚轮。
5. 单击宠物打开 ChatGPT。选择“隐藏”后，双击系统托盘里的鹦鹉图标恢复；再次运行 MacPet.exe 也可恢复已有实例。
6. Windows 版保留原版形象与全部 9 个 GIF，没有专注或喂番茄功能。

版本选择：普通 Intel / AMD 64 位电脑下载 x64；Windows on ARM 设备下载 arm64。
适用于 Windows 10 / Windows 11 的对应 64 位版本。该发行包未进行商业代码签名，首次运行可能显示未知发布者；请核对来自本项目 GitHub Release。

设置及表情存放在 %LOCALAPPDATA%\MacPet。删除表情只把应用管理的副本放入回收站，不影响导入来源。升级前退出旧版，再替换程序文件，保留本机设置。
