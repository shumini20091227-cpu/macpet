# MacPet 互动版 2.0 Beta 2

独立的 Mac 衍生版，保留 1.2.2 的表情、动画、管理和省电功能。

右键 → 键盘互动 → 选择任意表情 → 启用打字联动。停键 0.5 秒后恢复原表情。关闭联动立即恢复。联动不会覆盖持久保存的原表情选择。

首次启用需要 macOS 输入监控权限；系统安全输入可能暂停检测。仅响应按键活动，不读取字符、不记录内容、不联网传输。

独立 Bundle ID local.macpet.interactive，数据目录 ~/Library/Application Support/MacPetInteractive，不改动原版数据。包含相同九个内置 GIF；原版后续导入的文件可手动导入互动版。

当前为本地 Beta：已编译和回归测试；全局键盘联动需在授权后进行实际交互验收。

## Beta 2：键盘联动恢复修复

授权后自动重连，恢复唤醒及应用激活后的监听；右键菜单显示关闭、等待权限、正在监听状态。表情解码移出按键监听回调，减少回调超时风险。停键恢复仍为 0.5 秒。

应用为本地临时签名，更新后的二进制身份可能变化：系统设置里旧权限开关打开不代表新版已获授权。若显示等待权限，在输入监控中移除旧条目，重新添加当前应用并开启，然后退出重开。请将应用安装到固定位置后授权。重新授权后的键盘联动已经用户实测确认。

仅保存监听状态及是否收到过按键事件的诊断标记，不保存按键字符、按键码或输入内容。
